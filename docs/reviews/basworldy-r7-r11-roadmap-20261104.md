## 五、冻结原则与阶段性交付

1. 先核对真实来源、使用同一模板只开发一次；已 PASS 的 173 页不重复研发。
2. 每轮先进行技术 UAT，再交付 **5–8 个不同类型真实页面**（少于 5 时交付该轮全部）给 Owner 审核；发现同模板 Bug，一次修复并全批回归。
3. 来源 403 请 Owner 正常 Chrome 打开后另存 MHTML；不绕过访问控制，不伪造页面。
4. 新功能和相似度阈值不增项；不能将普通像素误差得分说成真实来源-vs-本地 SSIM。
5. 不触碰 WWW/ERP/Production，不合并 GitHub main；保留本地 SHA 清单、源档、回滚依据。
