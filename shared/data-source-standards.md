# Data access and verification
Allowed status: AUTHORIZED, NOT_CONNECTED, NO_ACCESS, UNKNOWN. AUTHORIZED means authorized account and appropriate property/site access were really confirmed. Data presence is not proof of live access.
Record for each quantitative source: account/property, channel, extraction time, source period, timezone, filters, country/language, aggregation, consent caveats, reference to source and data quality. Restrict output to share-safe metadata.
S1 prefers **12 complete months**, with YoY when comparable historical periods genuinely exist. Flag missing GA4/GSC access, sampling/thresholding, duplicate tags, bots and mismatched attribution.
Sales: reconcile Woo/Shopify orders, paid/completed status, refunds, currency conversion and transaction-ID dedupe. B2B: distinguish valid qualified leads, CRM outcomes and spam from clicks/submissions. Never say a click is a sale.
Store customer/orders/GA4 exports, search terms with sensitive business information, credentials, audit screenshots or device configuration only in approved protected locations, not the public Skills repository.
