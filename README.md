# Andy WebDev Skills

Small, **public** repository of reusable website-development workflows for ChatGPT, WordPress/WooCommerce, and authorized remote tools.

## Available Skill

[Rapid WebDev](skills/rapid-webdev/SKILL.md) — continue existing website projects, reuse already accepted work, run local tests, and perform controlled Dev UAT without redoing finished stages.

## How to use in ChatGPT Plus (web)

Connect your existing GitHub and remote-desktop/MCP tools. Then say:

> Read `beyourlovercom/skills-webdev/skills/rapid-webdev/SKILL.md` from GitHub, then read my project's `AGENTS.md` and current GitHub work. Use the already-connected authorized DC on China Windows to continue the next approved local development milestone; run applicable tests, report proof, and leave Production and PR merges alone without separate approval.

ChatGPT can **read and follow** the GitHub file using connected tools. This is *not* the same as installing an automatically discovered native Skill. The document is guidance, not executable remote access on its own.

## Safety and size

This public repository intentionally contains **only documentation/workflow code**. Do not commit credentials, OAuth tokens, passwords, user sessions, device addresses, real customer or order data, product media, database dumps, build dependencies, or screenshot archives. Keep actual project-specific settings and approval decisions in the corresponding project repositories.

There is no requirement to install a new MCP server, upgrade GitHub solely for this small repository, or restart an already READY computer. Keep this repository lightweight and vendor-neutral.

## Project rules

Every target project's `AGENTS.md` takes precedence over this generic workflow. Source control, authenticated runtime evidence, test outcomes, and explicit owner approvals determine whether something is complete.
