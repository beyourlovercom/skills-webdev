# S1 — Multi-source research and pre-launch strategy

**Scope:** Shared, public workflow. Verify live project facts first; generated site-specific `skills/site-intelligence/SKILL.md` in the destination project's repo takes priority. No credential, real customer data or private commercial report belongs here.

## Input
Permissioned GSC / GA4 / Google Ads / Semrush / order-level aggregates / on-site search / keyword research. Prefer last 12 complete months, compare YoY when both periods exist. Record property, market, range, filters and data freshness. Never invent a connected data source.

## Procedure
1. Audit access and event integrity: GA4 conversion/key event definitions, Consent Mode where applicable, channel attribution, self-referrals, bots, duplicate conversions, Woo completed orders versus add_to_cart and B2B qualified leads versus form clicks.
2. Compare GSC queries-pages-countries and landing page engagement, Semrush visibility and Ads search terms with business transaction / lead quality evidence. Separate measured fact, proxy, qualitative inference and UNKNOWN.
3. Cluster intent by country/language/product/category; propose P0/P1/P2 information architecture and canonical ownership for the planned old/new relationship. Build before-launch primary keyword map, not just post-launch SEO recommendations.
4. Export structured `source-register.csv`, `data-quality.md`, `opportunity-matrix.csv`, `keyword-url-map.csv`, `event-plan.md` and `handoff-codex.md`; create a standalone Chinese Word report only when requested/available authoring tooling is used.
5. Include 30/60/90 day measurement checkpoints and confidence gaps; do not present estimations as historical analytics.

## Gate
Every important numeric conclusion is linked to a source and date range. Missing access is called out. Tracking clicks are not treated as sales or qualified leads. No publish permission implied.

## Acceptance record
Always report host/device, evidence references, exact Git SHA, executed tests and PASS/FAIL/OPEN, approval state, no-production effects and next bounded action. Never confuse this Markdown document with an executable integration.
