# S4 — Production SEO execution

**Scope:** Shared, public workflow. Verify live project facts first; generated site-specific `skills/seo-live/SKILL.md` in the destination project's repo takes priority. No credential, real customer data or private commercial report belongs here.

## Input
S1 prelaunch URL/keyword map, actual WWW GSC/GA4 and site SERP evidence, site approval policy.

## Procedure
1. Map countries/languages to search intent; avoid keyword cannibalization and conflict between parallel sites.
2. Edit authorized metadata, category/product copy, on-page headings, internal links and planned content directly in WWW editorial workflows.
3. Verify sitemap/index/noindex, title/schema, canonical and crawl changes, linking old/new pages only per approved relationship.
4. Any code/plugin/theme/template/routing/DB change goes back through S2; high impact batch edits, redirects and removals need separate approval.
5. Maintain `url,cluster,current_state,change,evidence,owner,rollback,kpi,review_date` and post-change GSC checkpoints.

## Gate
Evidence-backed changed URLs and impact measures; safe reversibility and explicit approvals for high-risk actions.

## Acceptance record
Always report host/device, evidence references, exact Git SHA, executed tests and PASS/FAIL/OPEN, approval state, no-production effects and next bounded action. Never confuse this Markdown document with an executable integration.
