# S6 — Quality-gated editorial cadence

**Scope:** Shared, public workflow. Verify live project facts first; generated site-specific `skills/content-automation/SKILL.md` in the destination project's repo takes priority. No credential, real customer data or private commercial report belongs here.

## Input
Approved publishing frequency/roles, GSC/SERP evidence, owned content assets, policy for draft and publishing.

## Procedure
1. Weekly plan topics from query gaps, active product/categories and SERP, with market-specific briefs and source notes.
2. Write evidence-based drafts, fact-check claims, verify originality/image license, SEO intent and links; use draft by default.
3. Only after explicit approval of frequency, publishing scope, credentials and quality gates, schedule in WP/authorized scheduler. Untested or unapproved articles remain Draft.
4. Review published URLs, crawl/index, conversion usefulness and quality; revise the plan without invented rankings.

## Gate
A failed QA or missing Owner-approved publication policy blocks auto-publish. Existing tools may not support scheduling; do not claim scheduled jobs exist.

## Acceptance record
Always report host/device, evidence references, exact Git SHA, executed tests and PASS/FAIL/OPEN, approval state, no-production effects and next bounded action. Never confuse this Markdown document with an executable integration.
